Loan Default Prediction ModelMIT Capstone Project

Problem

Retail banks' interest profit relies heavily on home loans, but loan defaults (nonperforming assets) can significantly reduce earnings. Traditional loan approval processes are manual, time-intensive, and prone to human bias and errors. Automating this process can help reduce financial risk from defaults, improve efficiency and scalability, and ensure unbiased lending decisions. In this project, we will build a classification model to predict whether a borrower will default on their home equity loan before it is approved.

Approach

To start, we evaluated 3 modeling types: Logistic Regression, Decision Tree, and Random Forest. Finding that the recommended model for this project is the Random Forest Classifier. It has the best test accuracy, 88.8%, and highest F1_score, 69.9% among all models tested. It also has the highest precision, 75.6% when it predicts a default and identifies 232 of 357 true defaulters. Finally, there is no overfitting with this model, and this model satisfies ECOA interpretability requirements. Moreover, the default configuration outperformed the tuned version across all key metrics, suggesting the scikit-learn defaults are optimal for this dataset.

Outcome

The Random Forest Classifier model was projected to flag about 65% of true defaulters, which prevented an estimated 1,300 defaults and $12.1M in avoided losses annually, with a payback period under two weeks. Paired with SHAP-based explanation reports for every rejected application, it delivered both a measurable lift in caught risk and the required audit trail.

Lensless Diffuser CameraSwarthmore College Senior Thesis

Problem

Traditional cameras require many resources and a complicated build. In this project, we look at a different type of camera — one that is cheaper, lighter, and easier to build than the traditional camera, known as the lensless diffuser camera. This project was adapted from Dr. Laura Waller's work at UC Berkeley and uses her open-source reconstruction code. It is made using a Raspberry Pi board, Raspberry Pi camera, and various household items like scotch tape, which is used as a diffuser in place of the lens in a traditional camera. This project studies the 2D capabilities of the diffuser camera and analyzes which reconstruction algorithm works best.

Approach

First the camera was built by stripping the lens off a Raspberry Pi camera module, calculating a 5mm focal length, and mounting a double-sided-tape diffuser in a foam-board-and-electrical-tape aperture at that distance. Then the system was calibrated using a Unicorn HAT LED grid and a 3D-printed stand to photograph a single red LED's caustic pattern, which the algorithm needs in order to model the camera's point spread function. For reconstruction, three algorithms were evaluated — FISTA, which took 100 iterations for mediocre results; Le-ADMM, which was fastest and sharpest but needed more training data than the setup could provide; and bounded ADMM, which matched FISTA's quality in just 5 iterations and ran fast enough to support the many trial images the project required.

Outcome

Lensless diffuser cameras are well on their way to becoming a sufficient substitute for a traditional camera. If they're able to replace traditional cameras, they could help reduce the amount of waste produced in manufacturing them. Moreover, Le-ADMM could be applied to get an image quality just as accurate as a traditional camera.

AR: Know where you are, know where you're safeResearch funded by the National Science Foundation (Award #1852538) at UT Austin

Problem

As a single woman in Los Angeles, personal safety is one of my highest priorities, but it can be difficult to determine the safety of any given neighborhood in spite of being a native Angeleno. This project aims to create an AR program using rape and sexual assault crime statistics for any given neighborhood, provided by the Los Angeles Police Department. I also considered bias throughout — displaying crime statistics lets a user see objectively where sexual crimes take place, rather than by reputation. Some neighborhoods have high crime statistics but are dangerous mainly to specific populations: Skid Row, for example, is considered one of the most dangerous places in LA, but most of the crimes there occur between people living in encampments, not to the general public. Ultimately, this project explores to what extent open crime data can inform women about their surroundings while eliminating bias.

Approach

First, I parsed an LAPD crime report for sexual assault and rape statistics using the Pandas library, including the latitude and longitude of each crime, then plotted those points over a map using qGIS. Finally, I built an interface in Unity to display the statistics, so a user could stand at a corner or on a street and know how many incidents occurred in each direction over the past year. The interface was kept simple to eliminate bias from the creator. The full code for each step can be found on my GitHub, linked below.

Outcome

Augmented reality has great potential to help people — using a phone camera to view crime data in geographical context could give anyone navigating a new area more confidence. The groundwork is done; next steps mostly involve live testing and finalizing the Unity interface. A careful user study would be needed to define parameters like safe grid size and to confirm the AR overlay doesn't mislead or distract from the real world. Ultimately, this program could extend across Los Angeles, and to any other city with open crime data.
